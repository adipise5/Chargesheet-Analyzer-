# UI

The workstation targets 1440px while retaining laptop overflow behavior. It uses a navy operational sidebar, neutral evidence workspace, teal/blue information states, amber review states, red contradictions, and green only for corroborated/verified states.

Overview, Analysis, Evidence, Timeline, Graph, Documents, and Ask Case are first-class tabs. Cytoscape powers the interactive graph and edge inspector. React-PDF uses a bundled local PDF.js worker. Clicking a citation switches to Documents at the exact source page. OCR corrections display original, vision candidate, confidence, and retained correction state.
